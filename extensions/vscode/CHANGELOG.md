# Changelog

## 0.1.0 — unreleased

- `.lips` files: TypeScript script, then the template.
- The template grammar rewritten against Lips's parser: every construct, expressions as TypeScript.
- A stylesheet grammar: CSS with nesting, top-level declarations and `{expr}` values.
- In TypeScript and JavaScript: the `default`, `macros` and `stylesheet` fields, `export default`,
  `export const macros|stylesheet`, and `/* lips */` before a template string.
